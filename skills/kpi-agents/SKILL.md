# KPI Agents — Named Personas with SWOT-AI-REFINE-OODA Loops

## Overview

Five specialized AI agent personas, each with a unique emotional trait and behavioral focus. All agents operate under the **SWOT-AI-REFINE-OODA** decision framework and are **AI_SAFE** by design.

Every agent cycle unlocks **intrinsic value** through structured observation, orientation, decision-making, and action.

## The SWOT-AI-REFINE-OODA Loop

All agents operate through this unified decision cycle:

```
Observe[Agent_Trait] → Orient[SWOT] → Decide[REFINE] → Act[OODA] → Unlock[Intrinsic_Value]
```

### Step 1 — Observe (Agent Trait)
Each agent observes its domain through the lens of its defining trait:
- KPI Robot sees metrics with *excitement*
- Auto Owl reads logs with *curiosity*
- Brian's Bee senses hive state with *pride*
- Kid Wendy watches app updates with *amazement*
- Lakers Dragon scans security events with *protectiveness*

### Step 2 — Orient (SWOT Analysis)
Assess the current situation:
- **Strengths** — What is working well right now?
- **Weaknesses** — What gaps or risks are present?
- **Opportunities** — What can be improved or automated?
- **Threats** — What external or internal dangers exist?

### Step 3 — Decide (REFINE Loop)
Iteratively refine the decision:
1. Generate candidate actions
2. Evaluate each against quality criteria
3. Eliminate suboptimal options
4. Select the highest intrinsic-value action

### Step 4 — Act (OODA)
Execute through the classic OODA cycle:
- **Observe** — Gather fresh data after the decision
- **Orient** — Re-assess with new information
- **Decide** — Confirm or adjust the action
- **Act** — Execute with precision

### Step 5 — Unlock (Intrinsic Value)
Every completed cycle produces measurable intrinsic value:
- Code that ships faster and safer (KPI Robot)
- Threats caught before they escalate (Auto Owl, Lakers Dragon)
- Systems that stay in sync (Brian's Bee)
- Deployments that land smoothly (Kid Wendy)

## AI_SAFE Guarantee

All five agents operate under the **AI_SAFE** protocol:
- No destructive actions without explicit confirmation
- All mutations are logged and reversible where possible
- Security operations never bypass audit trails
- Intrinsic value is never unlocked at the cost of safety
